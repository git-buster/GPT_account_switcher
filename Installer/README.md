# GPT Switcher installer

Author: git-buster

Double-click **ChatGPTDesktopSwitcher-Setup.msi**. Installs for the current Windows user, with desktop and Start menu shortcuts. Requires Windows 10/11, .NET Framework 4.8 and one complete supported official ChatGPT client.

Start with Windows is optional and initially off. It can also be changed in app settings; it starts only the switcher tray icon, without account windows. Uninstall from Windows Installed apps; account data and history are retained.

The first detected client path is saved locally. If it stops working after an update or move, use **Accounts and settings → Auto detect → Save settings**. Choose the installed or portable edition, rather than running both copies.
